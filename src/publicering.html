Publicering

Jag har valt att publicera via GitHub och Netlify. Jag har använt mig av denna metod under förra läsåret, men väljer att göra det igen då mitt minne försvagats och jag tolkar det som en rekommendation och inte ett krav att prova ett nytt sätt. I framtida uppgifter kommer jag troligtvis testa ett annat publiceringsverktyg för att bredda mina kunskaper inom dessa.

Varför Netlify?

Netlify skiljer sig från andra typer av webbhotell som använder FTP, eftersom jag haft möjligheten att koppla Netlify till GitHub, där jag versionshanterar min kod. Vid varje push till GitHub, uppdateras min webbplats hos Netlify.

På Netlify kan jag publicera webbplatser som är byggda med bland annat HTML och CSS, och det har även stöd för ramverk, exempelvis Bootstrap och Tailwind.

Kostnad

Netlify har olika alternativ gällande kostnad. Jag använder mig av gratisversionen eftersom den är tillräcklig för min laboration, men det har också sina begränsningar.

Fördelar och nackdelar

En fördel med Netlify är att man som innan nämnt kan ha det kopplat till GitHub. Tidigt i förra läsåret kopierade jag in min mapp med all kod till Netlify för en manuell deploy, men ju mer bekväm jag blev, desto mer började jag våga koppla ihop det med mitt GitHub-konto och märkte hur smidigt det var i stället för att manuellt lägga in all kod hela tiden. På så sätt kan jag versionshantera min kod och lagra den i GitHub, samtidigt som det automatiskt är koppla till Netlify.


En annan fördel med Netlify är att man får en nästan helt egen domän. Man kan välja vad webbplatsen ska heta, och sedna slutar den på ".netlify.app". Det underlättar dock om man har flera laborationer att kunna namnge sina domäner för att hålla bra reda på dem.


En nackdel med Netlify är dock att det kan ta en stund att komma in i hur det fungerar, speciellt om man är nybörjare på detta. Man kan även behöva göra lite research som jag behövt göra för vilka kommandon som ska användas för att webbplatsen ska byggas, i mitt fall npm run build vars sträng jag lagt in i package.json-filen. Gratisversionen har också sina begränsningar, men det är inte något jag ännu stött på problem gällande.

Mitt arbetssätt

Jag har arbetat med min webbplats i Visual Studio Code, och använt mig av Git/GitHub för att versionshantera det. Jag skapade ett repository i GitHub för att kunna göra en git push dit. Jag använde mig av git add . och git commit -m "Meddelande" och slutligen git push i terminalen i Visual Studio Code för att pusha det till GitHub.

Mina filer ligger i en src-mapp och därför valde jag att använda den mappen för publicering i Netlify. Jag kan därför arbeta som vanligt med min kod i Visual Studio Code, skicka iväg ändringarna till GitHub för att webbplatsen sedan med hjälp av GitHubs och Netlifys samarbete ska synas på länken. Detta arbetssätt tycker jag är smidigt.


På denna länk kommer du åt Netlifys hemsida.
